# Agent Note: 项目业务技能治理

Status: implemented

[English](2026-09-11-project-business-skills.md) | 中文

## 问题

项目成员需要复用业务指令，但不应因此获得服务器文件系统权限或部署可执行插件。可复用流程还需要证明其确切内容经过测试，保存持久化发布身份，并允许执行期间撤销权限。

## 决策

FastAPI 与 PostgreSQL 拥有项目内稳定的技能身份、每个技能至多一个可变草稿、不可变发布版本、隔离测试记录、授权和正式审计。项目内唯一的 kebab-case slug 不可变。版本号与测试运行编号在项目行锁下跨整个项目递增。复合外键确保当前版本与测试 Session 属于对应技能和项目。数据库触发器保护发布内容、工具集合、摘要、源草稿修订号、发布者与发布时间。

Specialist 与 Manager 可编辑和测试草稿；Manager 只能发布正常完成且获得人工通过判定的测试所对应的确切修订号与摘要。授权属于稳定技能，因此发布和回滚会改变后续轮次使用的版本，无需再次授权。退役会移除授权，永久禁止编辑草稿、发布和恢复，同时保留历史。

每次草稿测试拥有一个持久化 Project Session，其用途固定为 `business_skill_test`，只执行一个场景和一个轮次。专用记录入口使其不进入普通对话列表和恢复路径。只读 Agent 不注册 `propose_fact`，并在执行前拒绝禁止的工具；测试成功不会模拟写入或创建审批。生产环境的 `propose_fact` 继续遵守[项目 Fact 审批](../architecture/2026-09-06-xagent-fact-approval.md)。

启动事务创建空 Session，并将确切草稿与场景保存在持久化幂等响应中。Host 通过正常的技能与轮次操作接纳输入，在事件日志中仅记录一次真实接纳。运行期间仅起始账号可追加，且只有该账号可以结算确切 Session；终态拒绝冲突与迟到响应。结算或退役后，当前项目成员仍可读取测试记录。运行时判定先锁 Session 再锁技能；技能锁串行化授权变更，不可变版本正文无需写权限。

测试 factory 通过后端原子领取挂载同一个持久化 Session，在执行前发布真实 runtime header 和启动事件。该 header 复制发起 Project Session 已校验的绝对工作区，使部署提示词变量保留项目语义，同时测试组合不提供文件系统工具。先读取空记录再启动 Agent，无法阻止两个 Host 并发执行。单个事务重新校验当前权限并锁定 Session、技能和运行；只有首次发布拥有执行权，相同重放不能启动另一轮。挂载前取消竞争同一组锁，只结算尚未领取的空运行。领取成功后，由一个 Host 拥有取消、模型和工具结束等待、持久化 flush 以及结算。清理保留原账号凭证，但不沿用已中止的 transport 信号；当前权限失效时仍拒绝操作。

只读测试排除的生产写权限是不可变运行数据，不是当前草稿的投影；否则草稿编辑会改写历史报告的含义。工具策略在启动时保存该集合，结算与人工结论均不能修改。缺少这项证据的旧测试行不能通过推断迁移，因此预发布迁移拒绝非空旧格式测试表。Fact Consumer 独立拒绝测试用途注册，覆盖过期请求声明和插件替换，防止错误测试组合暴露生产写工具。

历史 transcript 在技能退役后仍可读取，因此不能授权执行。测试工具调用使用独立事务，检查当前账号与项目、确切的已挂载运行中 Session、活跃技能、固定策略摘要，以及运行记录中保存的不可变只读工具集合。草稿编辑不能替换该集合。同一退役锁阻止已分配但仍为空的测试在退役后挂载。缺失的历史工具集合无法从可变草稿恢复，因此其预发布迁移同样拒绝非空旧格式存储。

内存中的 `turn/end` 不代表最终追加已进入持久化存储。结算 owner 在释放和最终 flush 期间持续观察取消，随后在提交结算前决定终止原因。循环空闲时就移除观察器，会把最终追加等待期间的取消误报为完成或模型失败。结算开始后，固定结果与后端终态检查共同阻止迟到输出改写报告。

Business provider 复用[通用技能注册表](2026-07-05-skill-system.md)和[目录替换机制](2026-07-27-skill-catalog-hot-refresh.md)。每个轮次固定一个已发布技能版本及其完整工具集合。每次工具调用均通过 FastAPI 重新校验当前成员关系、账号启用状态、技能授权及退役状态。发布或回滚不会替换轮次固定的版本；撤权则拒绝下一次调用。Session 日志保留已加载正文，轮次结束时替换模型可见内容，为后续请求留下不含指令的历史标记。

Host 提供方拥有精确 Agent/请求注册和私有定义到版本的关系，公开定义不包含后端句柄。通用注册表将观测完整性与可选 `cacheable` 标记分离：权威 Business 目录可以发布，但不能在物理请求之间复用。返回不完整观测会抑制合法目录发布；将权威观测自动视为可缓存，则会把某个请求的目录泄漏给该请求之外的并发读取。每次加载仍必须获得精确后端重新授权。test Remote 只有在独立执行器注册后才能创建隔离运行，从而保留接纳与结算的明确归属。

每次发现独立拥有候选项观测：注册级共享的当前候选项槽会让并发读取或刷新使合法的在途加载失效。精确候选项归属在物理请求内弱持有，每次加载仍检查后端授权。提供方释放时使用注册信号中止 transport 并等待自有操作结束；响应后的取消检查会丢弃忽略 abort 的 transport 的延迟结果。transport 完成检查和提供方发布检查保护不同的 Promise continuation：取消可能发生在两者之间，因此提供方必须在最终 await 之后重新检查 scope 和调用方信号。即使可选不变量诊断被禁用，也必须执行这一检查。

收件箱插入捕获物理请求归属，领取将该归属绑定到精确轮次。prompt 回执在持久准入后返回，不等待模型工作；其专用归属状态保留到已接受轮次结束，而消息丢弃、请求或连接取消、Agent 释放会更早关闭该状态。环境中的异步上下文不能授权后来排队的轮次。等待完成的执行监听器仅在获得新的后端授权后委托，最终 guard 要求该精确执行对象已经接纳；更早监听器的 allow 不能替代它。请求取消立即关闭授权，但 Agent 保留固定版本、guard 和分发包装层，直到持久化轮次结束或 Agent 释放。进行中的回调集合为空不能证明执行已经结束：审批发布可能发生在回调之间，在分发开始前取消物理请求。包装层重新检查取消状态，并将物理生命周期合并到执行信号；请求清理只结算已经拥有的工作。投影在同步 Session 追加通知之外执行，以保留事件发布的原子性。

提示词组装同时过滤 Agent 本地工具和继承的注册。显式调用发生在组装之后，因此激活在请求 header 快照前收窄待用数组。模型工具调用发生在该请求记入日志之后，不改变其已冻结数组；下一次组装应用固定策略。激活记录使用现有的可忽略信封，让没有该事件声明的读取器无需改变结构格式版本就能安全保留日志。原始指令留在仅追加记录中；只有当前轮次的模型历史条目变为使用标记。

工具 schema 提供方在组装 waterfall 之前运行，排队轮次可共享一个运行区间而没有空闲通知。因此，匹配的持久化 `turn/end` 必须在下一次 schema 收集前同步释放旧目录限制，且只释放目录状态。将释放延后到组装完成，即使后续版本成功激活，也可能从其请求中静默遗漏新声明的工具。目录释放既不在追加通知内投影 Session 消息，也不移除取消 guard 和分发包装层；后两者保持独立的操作结算归属。

本决策在 [Business Profile 组合](2026-08-22-xagent-profile-product-shell.md)中增加受治理的 provider，继续禁用文件系统技能来源和开发能力。[认证与 Session 隔离规则](../architecture/2026-08-25-xagent-auth-session-runtime.md)仍是权威。这些记录各自保留独立理由，存储基础不取代其中任何一项。[已批准设计](../../../../docs/superpowers/specs/2026-09-11-xagent-phase-6-business-skill-design.md)定义完整产品流程。

只有持久化 `turn/end` 才结束指令生命周期：`agent/turn-stopping` 可通过 steering 继续同一轮次的下一步。Session 启动和在线清理都使用激活记录与技能调用记录识别已结束的指令条目，因此崩溃修复不会让旧正文与新固定版本同时生效。保留身份的单节点替换继承原始接纳，即使其追加时间位于另一个轮次。清理替换当前可见条目（包括已裁剪结果），并根据内容识别已有标记。无关检查点不能仅因替换了历史位置就继承技能接纳。[Session surface 规则](../architecture/2026-06-18-session-surface.md)独立强制工具结果替换只改变内容。运行时回调的 `finally` 拥有执行结算；可能卸载的 `tools/result` 监听器不能负责它自身作用域释放所等待的 promise。

在证据动态注册 `submit_cited_answer` 之前，声明中的检索工具对仍保持完整。这一唯一例外要求真实检索服务，以及由工具消费方私有 WeakSet 识别的存活 search 定义。复制定义和插件卸载都会撤销该识别。名称相等不能证明归属，预注册占位配套工具则会错误宣称可执行的证据访问。

审批等待发生在执行前策略与工具分发之间，不属于任一回调。前置的 Agent 作用域审批监听器始终委托，并将结果与物理生命周期进行竞争。清理只等待这一可取消回调，不等待无响应答复方；竞争会吸收迟到异常并保留已取消决定。这保护审批间隙，而不扩展通用执行 API，也不修改只读审批请求。

项目发现是活跃 Skill 下的固定项目读取，不是枚举无关项目的权限。Host 专用发布版本或运行证明只存在于精确 Agent 工具执行内部，随该绑定失效。FastAPI 在检索事务中重复相应的生产或测试授权，使直接后端调用与退役竞争都不能依赖先前的 Host 检查。Private 发现保留既有无需证明的可访问项目行为。查询结果可以为空，但收据固定授权范围不变。

## 考虑过的替代方案

**根据提供方名称或持久化错误文本推断不变量策略。** 草稿提供方名称不能标识已挂载运行所选的只读工具，第二 Skill 冲突也不会关闭原策略。诊断读取 TestRunner 的精确 Agent／定义／run 标识及不可变测试工具，并读取已激活运行时策略既有的拒绝锁定状态。接纳与 bundle 两个伴随插件消费这一 Host 私有关系；它们既不创建授权，也不复制运行时的错误分类。

**使用公开发现选择器或扩大所有 Project Session。** 两者都会让未绑定对话绕过活跃 Skill 策略，并将项目发现与跨项目权限混淆。私有执行证明与同事务重新授权同时保留 Project 限制和 Private 发现语义。

Browser 治理仅在内存保留一个活跃的账号、项目、Session 和连接代次。项目与普通 Session ID 选择请求范围，而不是技能记录；省略它们会使授权器无法验证所请求的对话。物理令牌仍是权限依据，服务的第二次检查阻止已认证请求内部调用不同范围。发布时展示确切草稿修订、合格测试和被排除的生产写权限。仅结果不确定的变更保留原幂等键与不可变意图；修订冲突重新加载权威内容，而不覆盖它。

**以 slug 相等认定请求归属。** 返回一个技能不会恢复此前的选择：每次选择独立拥有可取消的历史和测试记录分页。共享分页锁会让旧请求阻塞当前技能，而只检查 slug 会在切走再返回后接收迟到响应。同样，变更 Promise 结束不能证明后端成功。未保存的创建输入只在所属账号、项目、Session、角色及连接范围内保留，直到权威成功；跨范围保留会泄露草稿内容。

**从已渲染的范围字段推断表单归属。** React 可能合并失效与加载更新，因此切走再返回会渲染相同的范围字段，却不暴露中间的权限失效。单调递增的代次独立于渲染记录每次失效，并拒绝旧表单捕获的命令。同范围刷新保留代次，但场景还必须匹配选中 slug：目录刷新可能在安全范围不变时选择另一个技能。

**由 Session 事件拥有治理状态。** 项目内并发发布与授权必须独立于单个 Session 存续，并落实 PostgreSQL 项目访问控制；Session 日志负责执行证据。

**将技能存为工作区文件。** 文件权限无法在不授予业务用户服务器访问权的前提下表达项目成员关系、确切内容测试、当前版本选择与正式审计。

**每个版本生成一个插件。** 业务指令不能变成任意代码部署并引入重启和供应链影响。Provider 可复用注册表而不执行用户代码。

**只过滤继承的工具注册表。** Agent 自有注册不是继承条目，仍会对模型可见。组装过滤配合精确调用执行授权，可覆盖两种注册来源，无需把 Business 策略加入通用循环。

## 验证

- 真实 PostgreSQL 测试证明项目 RLS、worker 拒绝访问、API 最小权限、身份与版本不可变、精确引用、终止退役，以及存在技能数据、测试 Session 或技能审计时在 DDL 前拒绝降级。
- 治理测试证明精确修订发布、并发编辑冲突、幂等、稳定技能授权、回滚和立即撤权。
- 运行时及完整组合快照证明两种调用形式、单版本轮次固定、逐工具授权、正文日志、历史标记与测试只读隔离。两个 SDK 投影均包含激活事件。
- 确定性真实栈验收验证草稿测试、发布、授权与 Project Session 调用。修复后的 Browser/GIF 验证仍未完成，因为本地固定 BGE-M3 缓存不完整，且当次补全缓存未能访问 Hugging Face；远程发布前必须让精确构建提交完成该真实模型流程。

## 影响

只读测试不能执行生产 Fact 写入，因此发布必须展示这些权限，并保留独立 Fact 审批校验。每次工具调用会增加后端延迟，授权不可用时必须拒绝执行。不可变发布与终止退役限制了修复方式；降级要求技能存储、测试 Session 与技能审计记录全部为空。每轮单技能明确不支持合并工具许可集合。
