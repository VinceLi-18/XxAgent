# @xagent/dsh-ui-business-skill

[English](README.md) | 中文

通过工作台的单 occupant Slot `xagent.workbench.skills` 提供可选项目业务技能治理。插件挂载生成的 `xagentBusinessSkill` Remote，等待父 Slot 声明，并在声明或插件释放时移除 occupant 和请求。不变量伴随插件检查真实 Remote 身份、Slot 组件及注入快照的归属关系。

紧凑技能列表打开详情，顶部 Draft / Test / Publish / Authorize 进度由实际数据驱动。Specialist 可创建和编辑 Markdown 草稿、选择闭合主工具目录中的工具、运行场景、查看隔离测试记录并给出人工判定。Manager 还可发布、授权、取消授权、选择不可变版本和退役技能。服务器授权始终是权威。发布确认列出确切修订、合格测试与生产写权限；退役确认说明不可恢复及立即取消授权。历史测试报告展示不可变的 `unexecutedWriteTools`，不随当前草稿编辑变化。

控制器仅在内存保留当前账号、项目、普通 Session、角色和物理连接代次。账号、项目、Session、页签或连接变化会中止请求并丢弃旧响应。释放时先取消请求、发布一次失效通知，再移除订阅并等待请求结束。目录按 slug 去重并确定排序。每次技能选择独立拥有历史、测试记录请求及分页锁；改变选择会取消这些请求，即使随后返回同一个 slug。测试记录读取包含序号零，并从服务器返回的末尾序号游标继续。技能内容和重试身份均不进入浏览器存储。

每个新变更使用新的幂等键。仅 transport 结果不确定时提供显式重试，沿用原键和不可变请求。变更结果区分权威成功、拒绝、不确定、取消及未启动。校验或名称重复错误后仍可修改创建输入，同范围刷新也会保留输入；仅创建成功会重置表单。安全错误要求刷新，但不丢弃未保存表单。修订或策略冲突会重新加载权威详情并保留测试场景；编辑器不猜测修订，也不重试过期覆盖。账号、项目、Session、角色或连接代次变化会清除保留输入。空、加载、错误、阻塞和就绪状态均明确展示。键盘页签导航、带标签控件、可见焦点及减少动态效果设置支持响应式列表与详情布局。

快照的每个阶段都暴露单调递增的 `scopeEpoch`。范围失效会同步推进代次，因此返回相同账号和项目也不能恢复旧表单。面板以代次作为输入子树的 key，并随变更传入捕获的代次；控制器拒绝旧表单命令。同范围刷新保留代次，包括加载和错误阶段；若目录仍包含原选中 slug，就恢复该选择，否则选择首项。测试场景仅在其代次和 slug 同时匹配当前选择及已加载详情时展示和提交。

## Model Experience

### Human governance（人工治理）

#### What the model sees

本包不添加模型输入。`@xagent/dsh-business-skill` 拥有隔离草稿执行及生产指令加载；本包渲染它们的公开记录。

#### Token effect

浏览器包不增加提示词或输出 token。

#### KV Cache effect

本包不读写模型 KV Cache。

## Known Limitations and Deferred Work

- 界面提供有界列表与历史，不支持批量编辑或搜索。
- 刷新和重连从已授权 Remote 恢复记录；没有离线模式。
- Business Profile 组合与真实服务浏览器验收属于独立集成范围。
