# @xagent/dsh-fact

[English](README.md) | 中文

`@xagent/dsh-fact` 为 XAgent Business 项目会话提供受治理的 Fact 服务。它把模型提出的 Fact 准备为稍后的人工作审，提供已认证的浏览器读取和决策 Remote，并把持久决策事件追加到来源会话。

服务只从物理认证请求上下文接受提案权限，并为当前身份、权限修订、固定项目、会话、工具和工具调用签发精确且短时有效的委托凭证。浏览器 Remote 同样从连接上下文派生用户令牌和固定项目；调用方不能提交身份或所有权字段。

提案收据与 Outbox 身份保存在两个独立私有注册表中。会话持久化按事件序列范围读取它们的附件，并且只在 FastAPI 确认对应追加后提交。会话打开和 `agent/pre-step` 通过每个会话唯一的所有者拉取最多 32 条 Outbox 记录，追加普通 `fact/proposal-decided` 事件，且绝不启动轮次。

## 模型体验

### 受治理的 Fact 生命周期

#### 模型看到什么

提供方本身不增加提示词或工具模式。独立消费方可以只返回提案 ID 与 `pending` 状态。Outbox 交付把 `fact/proposal-decided` 追加为只进入日志、不进入表面的会话事件；只有独立消费方明确投影它后，模型才能看到该事件。收据、令牌和证据内容从不进入投影。

#### Token 影响

提供方及其决策事件本身不增加模型令牌。只有未来的消费方把事件明确投影到模型请求时，其有界公开字段才占用令牌。

#### KV Cache 影响

Outbox 交付只追加会话历史，不调度模型请求，因此不会使正在使用的 KV 缓存失效或增长。在独立消费方投影该事件之前，后续模型请求同样忽略它。

## 已知限制与延期工作

- 本包不注册 `propose_fact` 模型工具或其渲染器；它们属于独立的 Business Profile 插件。
- 每次会话打开或 pre-step 触发只读取一页 Outbox；其余记录等待后续触发。
- 私有和匿名会话不能准备、读取或决定受治理的 Fact。
